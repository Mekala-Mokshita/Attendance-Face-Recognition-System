# Attendance Face Recognition System

Face Recognition Attendance System built using Python, OpenCV, Face Recognition, SQLite, Streamlit, and Power BI.

## Features

- Face Registration
- Face Recognition Attendance
- SQLite Database Storage
- Streamlit Analytics Dashboard
- Power BI Dashboard
- Automatic Face Training

## Technologies Used

- Python
- OpenCV
- face_recognition
- SQLite
- Pandas
- Streamlit
- Plotly
- Power BI
